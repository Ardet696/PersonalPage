# PersonalPage

My personal static website — home, projects, blog posts, a CV and book reviews.

- Built with HTML5, CSS3, and vanilla JavaScript.
- Deployed with GitHub Pages via GitHub Actions (see `.github/workflows/deploy.yml`).
- Also stores the `main.tex` sources for the PDF version of the CV.

### Stack

- **HTML5** — semantic markup
- **CSS3** — custom responsive layout, shared base stylesheet
- **JavaScript** — small hover interactions and date reveals
